# Space Node Command Integration

## Overview
While Space Nodes operate headlessly and invisibly to standard users, they are fully trackable and manageable within the Wnode Command interface by administrators.

## Tree Placement
- **Visibility:** Space Nodes appear in the Command affiliate/fleet tree just like standard nodes, but are visually distinguished by their `AA:SP` archetype and `Nodlr IN` label.
- **Account Association:** They are permanently bound to the partner's Wnode account, which is created internally by Wnode admins. 
- **Isolation:** Space Nodes do not participate in or view the standard public affiliate network; their tree placement is strictly for administrative organization and revenue tracking.

## Telemetry & Financials View
When an admin selects a Space Node in Command, the interface displays:
- **Live Status:** Online/Offline indicator based on the telemetry heartbeat.
- **Metrics Dashboard:** Real-time graphs for `uptime`, `tasks_completed`, and `resource_usage`.
- **Earnings Ledger:** A breakdown of standard `earnings` and conditional `bonuses` accumulated by the node.

## Optional: Space Nodes Map Layer
To visually represent our aerospace network, Command may include an optional "Space Nodes" layer on the Fleet Map:
- **Orbital Tracking:** (Future phase) Approximate geographic/orbital representation of active space nodes.
- **Filtering:** A dedicated toggle to isolate and display only `AA:SP` nodes, allowing Wnode admins to easily differentiate ground-based mesh nodes from space-based infrastructure.
