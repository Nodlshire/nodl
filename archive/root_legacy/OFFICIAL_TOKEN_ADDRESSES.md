# Official Token Addresses

This document contains the official and canonical token address list for the Wnode ecosystem.

## Official Token

WEX is the **only** official token of the Wnode ecosystem.

- **Token Name:** WENODE
- **Token Symbol:** WEX
- **Contract Address:** `0xa382506695f825fe807C3f4D47aEB986046bdc57`
- **Network:** Polygon Mainnet
- **Total Supply:** 10,000,000 (Fixed supply)

Wnode maintains a single canonical token. No additional tokens will be created.

## Deprecated Tokens

The following WNODE tokens were early test deployments created during private-sale preparation. They were never used, never distributed, and contain no supply. They are fully deprecated and should not be interacted with.
