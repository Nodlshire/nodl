# Protocol Glossary & Terminology

| Term | Definition |
| :--- | :--- |
| **nodld** | Proprietary native Go compute daemon running on operator machines in RAM-isolated namespaces. |
| **CMD** | Command Telemetry Ingestion Service enforcing zero-synthetic telemetry and epoch routing. |
| **UPID** | Universal Provider Identifier—unique cryptographic identity assigned to each registered node. |
| **DeWi** | Decentralized Wireless subsystem managing LoRaWAN, 5G, and radio gateway mesh infrastructure. |
| **Soul-DAO** | Non-transferable identity governance model enforcing 1-Soul-1-Vote democratic control. |
| **WWEX** | Native utility and governance token used for node operator staking, slashing, and buyback-burn. |
| **L_mem** | Cryptographic memory-latency challenge proof enforcing physical hardware presence. |
| **T_jitter** | Randomized heartbeat offset preventing thundering-herd API spikes under heavy load. |
