# Network Topology & Tier Classification

Wnode classifies nodes into five terrestrial compute tiers plus orbital satellite nodes:

| Tier | Category | Specification | Primary Workload |
| :--- | :--- | :--- | :--- |
| **Tier 1** | Light Edge | 1–2 CPU Cores, 2GB RAM | Light Telemetry, M2M Routing |
| **Tier 2** | Standard Workstation | 4 CPU Cores, 8GB RAM | General Compute Micro-Tasks |
| **Tier 3** | High-Compute Desktop | 8+ CPU Cores, 16GB RAM | Parallel Task Execution |
| **Tier 4** | Enterprise Server | Dedicated Server, 32GB+ RAM | AI Inference & Batch Processing |
| **Tier 5** | DeWi Radio Gateway | LoRaWAN / 5G Transceiver | Wireless Mesh & Sensor Ingestion |
| **Space** | LEO Satellite Node | Orbital Satellite Substrate | Space Mesh Survivability |
