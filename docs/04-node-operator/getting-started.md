# Node Operator Getting Started Guide

## Quick Installation

### 1. Desktop Standalone App (Linux / Fedora / Ubuntu)
Download and run the native desktop installer from GitHub Releases `v1.0.3`:

```bash
curl -LO https://github.com/wnodeltd/wnode/releases/download/v1.0.3/nodl-desktop-linux-amd64
chmod +x nodl-desktop-linux-amd64
./nodl-desktop-linux-amd64 --token <YOUR_HEADLESS_TOKEN>
```

### 2. Headless Server / Daemon (`nodl-core`)
```bash
curl -LO https://github.com/wnodeltd/wnode/releases/download/v1.0.3/nodl-core-linux-amd64
chmod +x nodl-core-linux-amd64
./nodl-core-linux-amd64 --token <YOUR_HEADLESS_TOKEN>
```
