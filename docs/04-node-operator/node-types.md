# Node Types & Hardware Specifications

| Node Archetype | Minimum Specs | Recommended Hardware | Execution Environment |
| :--- | :--- | :--- | :--- |
| **Desktop Standalone** | 2 Cores, 4GB RAM | Intel i5/i7, 8GB+ RAM | `nodl-desktop` (System Tray GUI) |
| **Headless Core** | 1 Core, 2GB RAM | AMD EPYC / Xeon, 16GB RAM | `nodl-core` (systemd / CLI) |
| **ARM64 Edge** | Raspberry Pi 4 / 5 | 4GB RAM, NVMe | `nodl-core` (Linux ARM64) |
| **DeWi Gateway** | SX1302 Concentrator | Outdoor Gateway | `nodld` DeWi Plugin |
