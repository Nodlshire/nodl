# Aave Integration

## Overview
Wnode integrates with Aave to perform automated DeFi operations.

## Purpose
To secure the Aave protocol through decentralized liquidations and health factor monitoring.

## Architecture
Wnode nodes run Aave monitoring agents that track on-chain state and submit liquidation transactions via Flashbots.

## Revenue path
Liquidation penalties/bounties paid directly to the executing node operator.

## Test results
Smart contract interactions and health factor calculations verified.
