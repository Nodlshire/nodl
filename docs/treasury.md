# Machine Treasuries

Wnode enables decentralized networks, DAOs, and AI agents to manage their own fully autonomous onchain treasuries.

## Tether as a Treasury Foundation
A robust machine treasury requires stable liquid assets and inflation-resistant commodities. 

- **USDT**: Provides the highly liquid, fiat-backed foundation necessary for day-to-day M2M payments, yield strategies, and operational capital.
- **XAUt (Tether Gold)**: Provides a gold-backed RWA anchor. By holding XAUt, machine treasuries align with premier commodity markets, physically vaulted and allocated securely. 
- **Strategic Positioning**: This dual-asset treasury model perfectly aligns with commodity and digital asset initiatives in jurisdictions like Dubai and the DMCC, offering institutional-grade, attested backing via T-bills, cash, and physical gold.

## Algorithmic Treasury Governance (ICP)
To manage complex treasury allocations safely, Wnode integrates the Internet Computer (ICP) Network Nervous System (NNS) architecture.
- **Neuron Staking**: Treasuries can lock operational capital into NNS neurons, utilizing age premiums and compounding maturity to grow the treasury trustlessly.
- **Liquid Democracy**: Treasury multi-sig structures implement automated vote delegation (following) and decentralized consensus voting to adapt to dynamic network conditions.
- **MULTI/DEX Routing**: Utilizing advanced ICP-native decentralised exchanges, treasuries can algorithmically rebalance portfolios across native and `ckToken` assets securely stored in persistent canister stable memory.
