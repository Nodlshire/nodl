# Bitso Integration Synopsis
**WUID:** 190013-0617-26-IN
**Category:** Payments / LATAM Corridors / Stablecoin Settlement

Bitso is a Regulated LATAM-focused cryptocurrency platform and institutional liquidity clearinghouse for stablecoin and cross-border settlement.

## Architecture
Stateless RESTful API and WebSocket payload routing integration utilizing secure cryptographic payload signatures. Operates as a chain-agnostic stablecoin bridge and automated localized fiat clearing network across Latin America (SPEI, Pix).
