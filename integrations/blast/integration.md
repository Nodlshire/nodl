# Blast L2 Integration Overview

## What is Blast?
Blast is an Ethereum Layer 2 optimistic rollup. Its core differentiator is native yield. ETH bridged to Blast is automatically staked in Lido, and stablecoins (USDB) are deposited into MakerDAO. The resulting yield is automatically passed down to the L2 users and dApps natively.

## Why Wnode Integrates with Blast
Because Blast natively rebases ETH and USDB balances, capital efficiency is extremely high. Wnode integrates with Blast to provide automated yield compounding and point harvesting (Blast Points & Blast Gold) across native dApps.

## How Wnode Interacts with Blast
Wnode utilizes standard EVM RPCs but incorporates logic to account for the native rebasing mechanics of the underlying assets. Agents interact with native Blast dApps (e.g., Thruster DEX, Orbit Protocol) to loop yield and claim Blast Gold distributions.

## Example Agent Workflows
- **Yield & Point Looping**: Wnode bridges user ETH to Blast. It deposits the ETH into a native lending protocol, borrowing USDB, and depositing it into an LP pool. The user earns the native Lido yield on their ETH, native Maker yield on the USDB, LP trading fees, Blast Points, and dApp-specific Blast Gold.

## Activation Steps
1. Connect to the Blast L2 RPC.
2. Use the official Blast bridge to port ETH/USDC to the network.
3. Set `ENABLE_BLAST_AUTO_FARMER=true`.

## Limitations
- Airdrop and points ecosystems are highly volatile and opaque. The actual APY generated by farming Blast Gold cannot be realized until the specific dApp executes its Token Generation Event (TGE).

## Future Upgrade Path
