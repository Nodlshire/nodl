# Chainlink Integration

This integration connects Wnode to Chainlink.

## Status
Integrated — Activation Coming Online

## Overview
Chainlink is a decentralized oracle network that enables smart contracts to securely interact with real-world data and services that exist outside of blockchain networks. This integration allows Wnode operators to directly supply and consume tamper-proof data feeds.

## SDK Usage
```ts
import { chainlink } from "./sdk";

chainlink.ping();
```
