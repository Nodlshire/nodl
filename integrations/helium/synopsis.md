# Helium Integration Synopsis
**WUID:** 190008-0617-26-IN
**Category:** DePIN / IoT / Mobile (Solana)

Helium is a Decentralized physical infrastructure network (DePIN) on Solana for IoT and Mobile coverage.

## Architecture
Integrates Wnode sovereign compute network with Helium Network on Solana. Enables deterministic off-chain computing resources to interface with DePIN, processing network health, carrier offloads, and automated reward claims.
