# Wnode Integrations Index

Welcome to the Wnode Public Integrations Index.

### Decentralized Finance (DeFi) & DEXs
- [Aave Protocol](./aave) — Decentralized liquidity protocol featuring E-Mode and flashloan liquidations.
- [Balancer](./balancer) — Automated portfolio manager and liquidity provider with zero-capital flash loans.
- [Curve](./curve) — AMM optimizing volatile assets (V2) and crvUSD soft-liquidations via the LLAMMA algorithm.
- [Frax Finance](./frax) — Stablecoin ecosystem featuring automated AMOs and Fraxlend isolated pool liquidations.
- [Liquity](./liquity) — Interest-free borrowing protocol heavily reliant on Keeper liquidations and Stability Pools.
- [Uniswap](./uniswap) — Automated liquidity protocol featuring concentrated liquidity management.
- [MakerDAO](./makerdao) — Decentralized credit platform issuing the DAI stablecoin via collateralized vaults.
- [Synthetix](./synthetix) — Decentralized synthetic asset issuance with automated c-ratio and liquidation mechanics.
- [SushiSwap](./sushiswap) — DEX ecosystem providing limit order execution and Kashi lending markets.
- [Yearn Finance](./yearn) — Yield aggregation protocol requiring automated harvesting across DeFi strategies.
- [Morpho Blue](./morpho) — Permissionless lending protocol utilizing isolated markets and highly lucrative liquidation pools.
- [Maverick](./maverick) — Dynamic distribution AMM requiring algorithmic re-centering to maximize LP capital efficiency.
- [Kamino](./kamino) — Solana lending and automated liquidity management requiring leveraged yield looping.
- [MarginFi](./marginfi) — Solana portfolio margin protocol heavily reliant on ultra-fast liquidators.
- [Solend](./solend) — Solana lending protocol featuring volatile isolated pools and high liquidation bounties.
- [Jupiter](./jupiter) — Solana DEX aggregator requiring Keeper bots to crank DCA and limit orders.

### Infrastructure & Oracles
- [Chainlink](./chainlink) — Decentralized oracle networks and smart contract automation (Keepers).
- [EigenLayer](./eigenlayer) — Restaking primitive providing cryptoeconomic security for Actively Validated Services.
- [EigenDA](./eigenda) — Massive-scale Data Availability AVS requiring high-bandwidth Node Operators to sign KZG commitments.
- [Lagrange](./lagrange) — ZK Coprocessor network utilizing EigenLayer State Committees for cross-chain attestation.
- [Lido](./lido) — Liquid staking middleware for Ethereum distributing stake to Node Operators.
- [Rocket Pool](./rocketpool) — Decentralized liquid staking protocol allowing Node Operators to run 8-ETH minipools.
- [SSV Network](./ssv) — Distributed Validator Technology (DVT) network distributing key shares across Node Operators.
- [Obol Network](./obol) — DVT middleware utilizing Charon to form highly resilient Distributed Validator Clusters (DVCs).
- [Renzo](./renzo) — Liquid Restaking Token (LRT) protocol abstracting AVS delegation and EigenLayer strategy management.
- [Ether.fi](./etherfi) — LRT protocol utilizing Operation Solo Staker to distribute validator keys via DVT.
- [Kelp DAO](./kelp) — Liquid Restaking protocol allowing native ETH and LST deposits for restaking yield aggregation.
- [Pyth Network](./pyth) — High-frequency pull oracle network requiring Keepers to push price updates on-chain.
- [Syndicate](./syndicate) — Transaction infrastructure and ERC-4337 Account Abstraction bundler networks.
- [Berachain](./berachain) — L1 utilizing Proof-of-Liquidity requiring validators to actively manage BGT emission bribes.
