# Integration Synopsis: pactus

## Overview
pactus is a protocol integrated into the Nodl network.
Execution Model: Sovereign Layer 1 Blockchain
Consensus/Validation: Solidified Proof of Stake (SPoS)

## Revenue Paths
- Direct Revenue: Transaction fees, Staking validator yield
- Indirect Revenue: None
- Tokenomics: PAC utility and staking token

## Machine-to-Machine Use Cases
Machine Payments: False
Automatable Endpoints: None
