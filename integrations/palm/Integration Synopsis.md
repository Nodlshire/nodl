# Integration Synopsis: palm

## Overview
palm is a protocol integrated into the Nodl network.
Execution Model: EVM-compatible Ethereum sidechain
Consensus/Validation: IBFT-2 Rotating Proof of Authority (PoA)

## Revenue Paths
- Direct Revenue: Gas fees in PALM/DAI
- Indirect Revenue: None
- Tokenomics: PALM native currency

## Machine-to-Machine Use Cases
Machine Payments: False
Automatable Endpoints: None
