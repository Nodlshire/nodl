# Integration Synopsis: paraswap

## Overview
paraswap is a protocol integrated into the Nodl network.
Execution Model: Off-chain aggregation price-routing with on-chain executor settlement
Consensus/Validation: N/A

## Revenue Paths
- Direct Revenue: Positive slippage sharing mechanism, Partner API access monetization
- Indirect Revenue: None
- Tokenomics: PSP utility token

## Machine-to-Machine Use Cases
Machine Payments: True
Automatable Endpoints: https://api.paraswap.io/prices, https://api.paraswap.io/transactions
