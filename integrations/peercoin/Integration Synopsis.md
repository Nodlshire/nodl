# Integration Synopsis: peercoin

## Overview
peercoin is a protocol integrated into the Nodl network.
Execution Model: Sovereign Proof-of-Stake / Proof-of-Work blockchain
Consensus/Validation: Hybrid PoW/PoS using Coin-Age calculation

## Revenue Paths
- Direct Revenue: Transaction fees
- Indirect Revenue: None
- Tokenomics: PPC utility and block rewards

## Machine-to-Machine Use Cases
Machine Payments: True
Automatable Endpoints: None
