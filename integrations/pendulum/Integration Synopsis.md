# Integration Synopsis: pendulum

## Overview
pendulum is a protocol integrated into the Nodl network.
Execution Model: Sovereign Layer-1 optimization for Forex/Fiat routing
Consensus/Validation: Polkadot Parachain validation mechanics

## Revenue Paths
- Direct Revenue: Transaction fees in native fiat stablecoins or native PEN token
- Indirect Revenue: None
- Tokenomics: PEN native utility token

## Machine-to-Machine Use Cases
Machine Payments: True
Automatable Endpoints: None
