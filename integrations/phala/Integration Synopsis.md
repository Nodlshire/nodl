# Integration Synopsis: phala

## Overview
phala is a protocol integrated into the Nodl network.
Execution Model: Off-chain verifiable confidential computation
Consensus/Validation: TEE remote hardware attestations

## Revenue Paths
- Direct Revenue: Gas-free execution options, Enclave computing resources paid in PHA
- Indirect Revenue: None
- Tokenomics: PHA utility and staking token

## Machine-to-Machine Use Cases
Machine Payments: True
Automatable Endpoints: None
