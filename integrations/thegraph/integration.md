# TheGraph Integration

This integration connects Wnode to TheGraph.

## Status
Integrated — Activation Coming Online

## Overview
The Graph is a decentralized protocol for indexing and querying data from blockchains. This integration allows Wnode applications to seamlessly build and consume subgraphs to query network data using GraphQL.

## SDK Usage
```ts
import { thegraph } from "./sdk";

thegraph.ping();
```
